# 📘 မေးခွန်းစာစောင် ထုတ်စက် (Exam Paper Generator)

စာအုပ်/မေးခွန်းဟောင်း **ဓာတ်ပုံ**တွေကနေ မေးခွန်းဘဏ် တည်ဆောက်ပြီး၊ အခန်း/အမှတ်/ခက်ခဲမှုအလိုက် မေးခွန်းစာစောင် ထုတ်ပေး၊ ကျောင်းသားအဖြေလွှာကို ပြန်စစ်ပေးတဲ့ web app ပါ။ GitHub Pages ပေါ်မှာ server မလိုဘဲ run ပါတယ်။

## လုပ်ဆောင်ချက်များ

1. **① မေးခွန်းဘဏ်** – မေးခွန်း + အဖြေ ဓာတ်ပုံတွေ တင်ပါ။ Claude AI က မေးခွန်းတိုင်းကို စာသားအတိုင်း ကူးယူပြီး အခန်း၊ အမှတ်၊ ခက်ခဲမှု (လွယ်/အလယ်/ခက်) ခွဲပေးပါတယ်။ ဇယားထဲမှာ ပြန်ပြင်နိုင်ပါတယ်။
2. **② မေးခွန်းထုတ်**
   - **အမြန်ထုတ်** – ၁၀၀ မှတ်ဖိုး / ၅၀ မှတ်ဖိုး / စိတ်ကြိုက်အမှတ် (လွယ် → ခက် ရောနှော)
   - **Command** – `အခန်း ၁ က ၅ မှတ်ဖိုး ၂ ပုဒ်၊ အခန်း ၃ က ၁၀ မှတ်ဖိုး ခက်ခက် ၁ ပုဒ်` လိုမျိုး ရိုက်ထည့်ပါ
   - **ကိုယ်တိုင်သတ်မှတ်** – အခန်း/အမှတ်/ခက်ခဲမှု/ပုဒ်ရေ ဇယားဖြင့်
   - Print ထုတ်နိုင်၊ အဖြေပါ/မပါ ရွေးနိုင်၊ သိမ်းထားနိုင်
3. **မေးခွန်းတွေဟာ တင်ထားတဲ့ ဓာတ်ပုံထဲကပဲ ဖြစ်ပါတယ်** – AI က မေးခွန်းအသစ် မထွင်ပါ။ Command ကို AI က နားလည်ပေးရုံသာ ဖြစ်ပြီး မေးခွန်းရွေးတာကို မေးခွန်းဘဏ်ထဲကနေ code နဲ့ပဲ ရွေးပါတယ်။
4. **③ အဖြေစစ်** – သိမ်းထားတဲ့ စာစောင်ကို ရွေး၊ ကျောင်းသားအဖြေလွှာ ဓာတ်ပုံ တင်ရင် ဓာတ်ပုံထဲက မူရင်းအဖြေနဲ့ တိုက်စစ်ပြီး မေးခွန်းတစ်ပုဒ်ချင်း အမှတ်နဲ့ မှတ်ချက် ပေးပါတယ်။

## GitHub Pages ပေါ် တင်နည်း

1. GitHub မှာ repository အသစ်တစ်ခု ဖန်တီးပါ (ဥပမာ `exam-generator`)။
2. ဒီ folder ထဲက ဖိုင်တွေ (`index.html`, `app.js`, `style.css`, `README.md`, `.nojekyll`) ကို upload လုပ်ပါ။
   ```bash
   git init
   git add .
   git commit -m "Exam paper generator"
   git branch -M main
   git remote add origin https://github.com/<username>/exam-generator.git
   git push -u origin main
   ```
3. Repository → **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** → Save
4. ၁–၂ မိနစ်အကြာ `https://<username>.github.io/exam-generator/` မှာ ဖွင့်လို့ရပါပြီ။

## စတင်အသုံးပြုနည်း

1. API key ယူပါ — နှစ်မျိုးထဲက ကြိုက်တာ သုံးနိုင်ပါတယ်:
   - **Gemini (Google)** – [aistudio.google.com/apikey](https://aistudio.google.com/apikey) မှာ အခမဲ့ ယူနိုင်ပါတယ်
   - **Claude (Anthropic)** – [console.anthropic.com](https://console.anthropic.com/settings/keys)
2. App ထဲ **⚙ ဆက်တင်** မှာ AI ရွေးပြီး key ထည့်ကာ **🔌 Key စမ်း** → **💾 သိမ်း** ပါ။ အပေါ်ညာဘက် dropdown ကနေ Claude ↔ Gemini အချိန်မရွေး ပြောင်းနိုင်ပါတယ်။
3. ① မှာ ဓာတ်ပုံတင် → ② မှာ ထုတ် → 💾 သိမ်း → ③ မှာ အဖြေစစ်

## သိထားသင့်တာများ

- **Key အများကြီး** ထည့်ထားနိုင်ပါတယ် (တစ်ကြောင်းကို တစ်ခု)။ Key တစ်ခု limit ပြည့်ရင် (သို့) မှားနေရင် နောက် key ကို အလိုအလျောက် ပြောင်းသုံးပါတယ်။
- **API key** ကို သုံးသူရဲ့ browser (localStorage) ထဲမှာသာ သိမ်းပြီး သက်ဆိုင်ရာ AI (Anthropic / Google) ဆီကိုသာ ပို့ပါတယ်။ Public repo ထဲ key မထည့်ပါနဲ့။ Link ကို အခြားသူတွေနဲ့ share ရင် သူတို့ကိုယ်ပိုင် key ထည့်ရပါမယ်။
- **မေးခွန်းဘဏ်** ကို browser ထဲမှာ သိမ်းပါတယ်။ ကွန်ပျူတာ/browser ပြောင်းရင် **⬇ JSON သိမ်း** ပြီး **⬆ JSON ဖွင့်** နဲ့ ရွှေ့ပါ။ (Backup အဖြစ်လည်း သိမ်းထားပါ)
- ဓာတ်ပုံ ကြည်လင်လေ ပိုတိကျလေ ဖြစ်ပါတယ်။ အဖြေက သီးခြားစာမျက်နှာမှာ ရှိရင် မေးခွန်းစာမျက်နှာနဲ့ **တစ်ခါတည်း** တင်ပါ (တစ်ကြိမ်လျှင် ၂၀ ပုံအထိ တွဲဖတ်ပါတယ်)။
- AI ထုတ်ယူတဲ့ အခန်း/အမှတ်/ခက်ခဲမှု နဲ့ အဖြေစစ် အမှတ်ပေးချက်ကို ဆရာ/ဆရာမ ပြန်စစ်ပါ။
- ဓာတ်ပုံ တစ်ကြိမ်ဖတ်တိုင်း API ကုန်ကျစရိတ် အနည်းငယ် ရှိပါတယ်။ Gemini အခမဲ့ key သုံးနိုင်သလို Claude မှာ Sonnet / Haiku ရွေးရင် ပိုသက်သာပါတယ်။ မြန်မာလက်ရေး ဖတ်တဲ့ အတိအကျ AI အလိုက် ကွာနိုင်လို့ နှစ်ခုလုံး စမ်းကြည့်ပါ။
